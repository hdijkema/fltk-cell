fltk-cell

Small cells. Exact values.

Draw and edit typed values in FLTK tables. Keep your data model, preserve decimal precision and create editors only where they are needed.

Editing stays explicit

Editors propose values. Your application validates, commits and redraws.

fltk-cell / usageC++17
#include <fltk_cell.h>

fltk_cell::TableCellNumberDrawer number;
number.format.decimals = -1;

fltk_cell::CellValue value =
    fltk_cell::Decimal{"9007199254740993.125"};

// Inside your table's draw_cell callback:
number.draw({ {x, y, w, h}, value, style, {} });
